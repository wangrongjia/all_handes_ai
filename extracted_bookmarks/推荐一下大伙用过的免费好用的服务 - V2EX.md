我的个人网站已经稳定运行了 7 年+，除了域名之外没有在其他的地方投入过费用，个人觉得一个网站活的久的关键就是尽可能的少投入钱，大部分的个人站都没啥流量，如果 0 投入，那即便是没流量也基本会放着，最多不更新，一旦要涉及到投入钱，那可能就会权衡利弊，在服务器到期时顺便下线了。感谢互联网提供了很多免费服务，让我们可以低成本的运营个人站，这里分享下我用到的几个免费服务，其他大伙分享更多

  1. Github Pages：免费托管静态网站
  2. Cloudflare CDN：免费 CDN 服务
  3. Cloudflare Pages：免费托管静态网站
  4. Cloudflare R2：对象存储服务，免费 10GB 存储
  5. Vercel：支持 Serverless Functions ，尤其是跟 Next.js 配合更是天衣无缝，可以免费实现一些动态服务
  6. Supabase：免费一个 PostgreSQL 数据库
  7. ClawCloud：容器云平台，每月免费 5$



详细的介绍和规则可以看这里： <https://blog.ops-coffee.cn/s/free-services-for-website-deployment.html> ，欢迎朋友们继续补充
