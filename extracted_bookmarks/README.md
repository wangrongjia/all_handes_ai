# V2EX 书签内容提取器

这个目录包含了从V2EX网站提取的书签内容，已转换为Markdown格式。

## 提取统计

- **总链接数**: 155个
- **V2EX链接数**: 148个
- **成功提取**: 143个文件
- **提取时间**: 2025-07-28

## 文件格式

每个Markdown文件包含以下信息：
- 文章标题
- 原始链接
- 提取时间
- 文章内容（转换为Markdown格式）

## 使用的工具

使用了自定义的Python脚本 `bookmark_extractor.py` 来：
1. 解析HTML书签
2. 提取V2EX链接
3. 获取网页内容
4. 转换为Markdown格式
5. 保存到本地文件

## 主要功能

- 自动识别V2EX链接
- 智能提取网页主要内容
- 处理中文文件名
- 避免重复文件名冲突
- 添加请求延迟避免被封

## 注意事项

- 部分文件可能存在编码问题
- 少数链接可能因为网络问题或页面不存在而提取失败
- 文件名中的特殊字符已被替换为下划线
